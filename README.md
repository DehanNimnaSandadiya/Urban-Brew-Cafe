# Urban Brew Café ☕

A modern, fully responsive website for a local café in Colombo, built from scratch for Koncepthive Web Dev Intern Task.

Urban Brew Café is a modern and responsive café website designed in Figma and developed using React. The project emphasizes clean design, consistent typography, reusable components, and smooth navigation. It features a hero section, about/services information, featured menu items, gallery, and a functional footer with contact and social links.

### Features
- Clean, modern design
- Fully responsive (mobile + desktop)
- Smooth navigation & scroll
- Semantic HTML + reusable components
- Built with React + Vite + Tailwind CSS
